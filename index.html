Sign-in UI · CSS + SVG

signin-scan-animation

A device-verification graphic for the moment a session needs re-authentication: a scan line sweeps a laptop drawing, lights it and the fingerprint chip in the accent colour, rests, and sweeps back — on a 3.5 second loop. No JavaScript, no images.

Live · loops

The card is a fixed dark specimen matching the source. Toggle it to see the widget adapt via one class.

Drop it in

Two files: a stylesheet and a block of markup. One instance per page.

CSS + HTML

<!-- once, in <head> -->
<link rel="stylesheet" href="signin-scan.css">

<!-- where the graphic goes; add ssa--light on a light card -->
<div class="ssa" role="img" aria-label="Verifying this device">
  … contents of signin-scan.html …
</div>

Web component — styles & SVG bundled in a shadow root

<script src="signin-scan.js" type="module"></script>

<signin-scan></signin-scan>
<signin-scan light></signin-scan>
<signin-scan style="--ssa-zoom: 1.4"></signin-scan>

Variables

Set these on .ssa or the <signin-scan> element.

TokenDefaultControls
--ssa-accent#2a77d7Scan line, glow, the “scanned” laptop and chip
--ssa-body-fill#242427Laptop shell and chip background
--ssa-body-stroke#5b5a5cLaptop outline before the line passes
--ssa-screen-fill#212123Screen fill before the line passes

--ssa-glyph-idle#6b6b6eFingerprint glyph, idle
